# 📝 Listify

Listify is a simple family to-do list website designed for everyday use.
It helps organize daily tasks into separate lists for family members,
shopping, locations, and other activities.

## 🌐 Use Listify

👉 [Open Listify](https://listify-rose-kappa.vercel.app/)

## ✨ Features

- Separate task categories
- Add tasks by typing and pressing Enter
- Mark tasks as completed
- Delete individual tasks
- Clear all tasks
- Tasks stored in a PostgreSQL database
- Tasks remain saved after refreshing the page
- Responsive user interface
- Pastel-themed user interface

## 🛠️ Technologies Used

- React
- JavaScript
- CSS
- Vite
- React Router
- Node.js
- Express.js
- PostgreSQL
- Neon PostgreSQL

## 🚀 Deployment

The Listify frontend is deployed on **Vercel**, the backend is deployed on **Render**, and the application uses **Neon PostgreSQL** for data storage.

- 🌐 **Frontend:** Vercel
- ⚙️ **Backend:** Render
- 🗄️ **Database:** Neon PostgreSQL
